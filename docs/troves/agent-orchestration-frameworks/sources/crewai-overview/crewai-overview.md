# CrewAI - The Leading Multi-Agent Platform

## Overview

CrewAI makes it easy for enterprises to operate teams of AI agents that perform complex tasks autonomously, reliably and with full control.

## Core Value Proposition

- Accelerate AI agent adoption and deliver production value
- Build crews of AI agents for complex tasks
- Visual editor + AI copilot or intuitive powerful API
- Production-ready from day one

## Platform Components

### CrewAI OSS
- Open-source orchestration framework
- High-level abstractions and low-level APIs
- Complex, agent-driven workflows

### CrewAI AMP (Agent Management Platform)
- Cloud: Full AI agent lifecycle management
- Factory: On-prem or private VPC deployment (AWS, Azure, GCP)

## Key Capabilities

### Easy
- Build crews that autonomously interact with enterprise applications
- Use tools to automate workflows
- With or without writing code

### Trusted
- Repeatable, reliable outcomes
- Workflow tracing, agent training, task guardrails

### Scalable
- Centralized management across business units
- Comprehensive monitoring
- Automatic serverless scaling

## Architecture

CrewAI is built on:
- **Orchestrate**: Planning, reasoning, memory, tools, knowledge
- **Build and Integrate**: Studio, APIs, tools, triggers
- **Observe and Optimize**: Tracing, training, testing, events
- **Manage and Scale**: Monitoring, permissions, serverless, teams

## Enterprise Features

- Visual editor and AI copilot
- Integrated tools and triggers
- Intuitive and powerful APIs
- Workflow tracing
- Agent training
- Task guardrails
- LLM and tool configuration
- Role-based access control
- Serverless containers

## Integration Support

- Gmail, Microsoft Teams, Notion, HubSpot, Salesforce, Slack
- Out-of-the-box and custom tools
- API-based integration

# LangGraph: Agent Orchestration Framework for Reliable AI Agents

## Overview

LangGraph is an agent runtime and low-level orchestration framework from LangChain that enables building reliable agents with low-level control.

## Key Features

### Human-in-the-Loop
- Prevent agents from veering off course with easy-to-add moderation and quality controls
- Add human-in-the-loop checks to steer and approve agent actions
- Built-in interrupts for agent control

### Expressive, Customizable Workflows
- Low-level primitives provide flexibility for fully customizable agents
- Design diverse control flows: single, multi-agent, hierarchical
- All using one framework with graph-based state machines

### Persistent Memory
- Built-in memory stores conversation histories
- Maintains context over time
- Enables rich, personalized interactions across sessions

### Streaming for Better UX
- First-class streaming with token-by-token output
- Shows agent reasoning and actions in real time
- Bridges user expectations and agent capabilities

## Architecture

LangGraph provides:
- **Stateful agents**: Built-in persistence for conversation memory
- **Human-in-the-loop**: Easy moderation and quality controls
- **Streaming**: Native token-by-token streaming
- **Low-level control**: Fine-grained control over agent execution

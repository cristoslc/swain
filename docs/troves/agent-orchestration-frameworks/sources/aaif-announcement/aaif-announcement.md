# Linux Foundation Announces the Formation of the Agentic AI Foundation (AAIF)

## Overview

The Linux Foundation announced the formation of the Agentic AI Foundation (AAIF) with founding contributions of leading technical projects including:
- Anthropic's Model Context Protocol (MCP)
- Block's goose
- OpenAI's AGENTS.md

## Key Announcement

> "Within just one year, MCP, AGENTS.md and goose have become essential tools for developers building this new class of agentic technologies," said Jim Zemlin, Executive Director of the Linux Foundation. "Bringing these projects together under the AAIF ensures they can grow with the transparency and stability that only open governance provides."

## Founding Projects

### Model Context Protocol (MCP) - Anthropic
- Universal standard protocol for connecting AI models to tools, data and applications
- Donated to ensure it stays open, neutral, and community-driven
- 97M+ monthly SDK downloads across Python and TypeScript
- Enterprise-grade infrastructure from AWS, Cloudflare, Google Cloud, Microsoft Azure

### goose - Block
- Open source, local-first AI agent framework
- Combines language models, extensible tools, and standardized MCP-based integration
- Provides structured, reliable, and trusted environment for agentic workflows
- Reference implementation for MCP
- Thousands of developers worldwide
- Block engineers active contributors to MCP steering committee

### AGENTS.md - OpenAI
- Simple, universal standard for project-specific guidance to AI coding agents
- Gives agents consistent source of repository and toolchain information
- Works across different repositories and toolchains
- Early adopter of MCP

## AAIF Mission

The AAIF provides a neutral, open foundation to ensure agentic AI evolves:
- Transparently
- Collaboratively
- In ways that advance adoption of leading open source AI projects

## Governance Model

- Vendor-neutral home for open source agentic AI projects
- No single company dominates
- Funding for critical community programs and research
- Building open protocols for seamless system interoperability

## Key Quotes

**Anthropic**: "Donating MCP to the Linux Foundation as part of the AAIF ensures it stays open, neutral, and community-driven as it becomes critical infrastructure for AI."

**OpenAI**: "For AI agents to reach their full potential, developers and enterprises need trustworthy infrastructure and accessible tools to build on. By co-founding the AAIF and donating AGENTS.md, we're helping establish open, transparent practices that make AI agent development more predictable, interoperable, and safe."

**Block**: "The AAIF is a vendor-neutral home for open source agentic AI projects where no single company dominates, providing funding for critical community programs and research."

## Enterprise Adoption

Cisco joined as a launch Gold member, with participation in:
- Agent2Agent (A2A) Protocol project
- AGNTCY project

The transition signals agentic AI is ready for enterprise adoption.

## Significance

The AAIF lays groundwork for a shared ecosystem of:
- Tools
- Standards
- Community-driven innovation

This creates neutral stewardship for open, interoperable infrastructure as agentic AI moves from experimentation into real-world production.

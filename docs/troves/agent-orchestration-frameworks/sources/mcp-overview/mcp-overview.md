# Model Context Protocol (MCP)

## Overview

MCP (Model Context Protocol) is an open-source standard for connecting AI applications to external systems.

## Analogy

Think of MCP like a USB-C port for AI applications. Just as USB-C provides a standardized way to connect electronic devices, MCP provides a standardized way to connect AI applications to external systems.

## What MCP Enables

- Agents accessing Google Calendar and Notion
- Claude Code generating web apps from Figma designs
- Enterprise chatbots connecting to multiple databases
- AI models creating 3D designs in Blender
- AI applications performing actions on behalf of users

## Benefits by Stakeholder

### Developers
- Reduces development time and complexity
- Easier integration with AI applications or agents

### AI Applications/Agents
- Access to ecosystem of data sources, tools and apps
- Enhanced capabilities and improved user experience

### End-users
- More capable AI applications
- Agents that can access data and take actions

## Ecosystem Support

MCP is supported across a wide range of clients and servers:

### AI Assistants
- Claude
- ChatGPT

### Development Tools
- Visual Studio Code
- Cursor
- MCPJam
- Many others

## Architecture

MCP enables AI applications to connect to:
- Data sources (local files, databases)
- Tools (search engines, calculators)
- Workflows (specialized prompts)

## Governance

MCP is now under the Agentic AI Foundation (AAIF) at the Linux Foundation:
- Neutral, open governance
- Community-driven development
- Vendor-neutral standard

## Getting Started

- Build servers to expose data and tools
- Build clients that connect to MCP servers
- Build MCP Apps for interactive experiences

## Key Characteristics

- Open standard
- Wide client support (build once, integrate everywhere)
- Growing ecosystem of data sources and tools
- Foundation for agent interoperability

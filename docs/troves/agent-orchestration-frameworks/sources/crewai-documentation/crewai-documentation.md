# CrewAI Documentation

## Mission Statement

> "Ship multi-agent systems with confidence"

Design agents, orchestrate crews, and automate flows with guardrails, memory, knowledge, and observability baked in.

## Core Concepts

### Agents
Compose agents with:
- Tools
- Memory
- Knowledge
- Structured outputs using Pydantic
- Templates and best practices

### Flows
Orchestrate:
- Start/listen/router steps
- State management
- Persist execution
- Resume long-running workflows

### Tasks & Processes
Define:
- Sequential processes
- Hierarchical processes
- Hybrid processes
- Guardrails
- Callbacks
- Human-in-the-loop triggers

## Enterprise Features

### Deploy Automations
- Manage environments
- Redeploy safely
- Monitor live runs from Enterprise console

### Triggers & Flows
Connect to:
- Gmail
- Slack
- Salesforce
- And more

Pass trigger payloads into crews and flows automatically.

### Team Management
- Invite teammates
- Configure RBAC
- Control access to production automations

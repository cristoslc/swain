# goose - Your Open Source AI Agent

## Overview

goose is a general-purpose AI agent that runs on your machine. Not just for code — use it for research, writing, automation, data analysis, or anything you need to get done.

> Note: goose has moved to the Agentic AI Foundation (AAIF) under Linux Foundation governance.

## Key Features

### Multi-Interface Support
- **Desktop app** for macOS, Linux, and Windows
- **Full CLI** for terminal workflows
- **API** to embed it anywhere
- Built in Rust for performance and portability

### Extensibility via MCP
- Connect to 70+ extensions — databases, APIs, browsers, GitHub, Google Drive, and more
- Uses Model Context Protocol (MCP) open standard
- Add community skills or build your own

### LLM Provider Support
Works with 15+ providers:
- Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure, Bedrock, and more
- Use API keys or existing Claude, ChatGPT, or Gemini subscriptions via ACP (Agent Client Protocol)

### Recipes
- Capture workflows as portable YAML configs
- Share with your team, run in CI
- Include instructions, extensions, parameters, and subrecipes
- Session recipes for complex workflows

### MCP Apps
- Extensions can render interactive UIs directly inside goose Desktop
- Buttons, forms, visualizations
- Agent-powered tools with MCP Apps

### Subagents
- Spawn independent subagents to handle tasks in parallel
- Code review, research, file processing
- Each runs in its own isolated session
- Keeps main conversation clean

### Security
- Prompt injection detection
- Tool permission controls
- Sandbox mode
- Adversary reviewer for unsafe actions

## Built on Open Standards

### Model Context Protocol (MCP)
- Universal standard for connecting AI agents to tools and data
- Goose was one of the earliest adopters
- Deepest integration in the ecosystem with 70+ extensions

### Agent Client Protocol (ACP)
- Standard for communicating with coding agents
- Goose works as an ACP server
- Connect from Zed, JetBrains, or VS Code
- Can use ACP agents like Claude Code and Codex as providers

### Agentic AI Foundation (AAIF)
- Goose is part of AAIF at the Linux Foundation
- Ensures vendor-neutral, community-governed, long-term open development

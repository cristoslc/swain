# Achievements

Tiered achievement system with shareable trophy cards.

AgentCraft includes a tiered achievement system with celebrations, a gallery UI, and shareable trophy cards.

## Unlocking Achievements

Achievements unlock automatically as you use AgentCraft. There are ~30 achievements across three categories:

| Category | Description |
| --- | --- |
| Discovery | Found by exploring features and UI elements |
| Mastery | Earned through skilled use of AgentCraft |
| Secret | Hidden achievements — keep exploring to find them |

## Rarity Tiers

Each achievement has a rarity that determines its celebration effects:

| Rarity | Toast Duration | Animation | Confetti | Screen Flash |
| --- | --- | --- | --- | --- |
| Common | 5s | Nearest hero waves | None | None |
| Uncommon | 6s | Nearest hero waves | None | None |
| Rare | 7s | Nearest hero jumps | Blue/white burst | Blue flash |
| Legendary | 10s | All heroes dance | Gold burst | Gold flash |

## Achievement Gallery (Hall of Glory)

Open the gallery from Settings > About tab > Hall of Glory (Achievements), or click any achievement toast when it appears.

### Visual States

- Unlocked — Full color with rarity border glow, title, and description. Click to see details and share buttons.
- Locked (non-secret) — Desaturated, visible title and description, dim border
- Locked (secret) — Shows "???" for title and "Keep exploring..." for description

### Filtering

Filter by category: All, Discovery, Mastery, or Secret.

A progress bar shows your overall completion percentage.

## Share Cards (Trophy Cards)

When you unlock an achievement, you can share it as a trophy card:

1. Copy to clipboard — Copies a 600x315px PNG image
2. Download PNG — Saves the card as a file
3. Share to X/Twitter — Opens a pre-filled tweet with the achievement info

Trophy cards include the achievement icon, title, description, rarity badge, and your progress count.

Share buttons appear on both achievement toasts and in the gallery detail view.

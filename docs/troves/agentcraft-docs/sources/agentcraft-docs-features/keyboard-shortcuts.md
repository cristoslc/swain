# Keyboard Shortcuts

Complete keyboard reference for AgentCraft.

Press ? at any time to open the keyboard shortcuts overlay.

## Hero Selection

| Key | Action |
| --- | --- |
| 1-8 | Select hero by priority slot |
| Space | Cycle idle/awaiting heroes (awaiting first) |
| I | Cycle idle heroes only |
| Shift+I | Cycle awaiting heroes only |
| E | Cycle error heroes |
| W | Cycle working heroes |
| Ctrl+I | Jump to first idle hero |
| Ctrl+E | Jump to first error hero |
| Ctrl+A | Jump to first awaiting hero |

## Control Groups

| Key | Action |
| --- | --- |
| Ctrl+1-9 | Assign selected hero to control group |
| Shift+Ctrl+1-9 | Add selected hero to control group |
| Alt+1-9 | Recall control group |

## Navigation and Panels

| Key | Action |
| --- | --- |
| Enter | Toggle side panel for selected hero |
| Escape | Close modal/panel or deselect |
| Tab | Cycle through selected hero's subagents |
| ` (backtick) | Toggle war table (file activity overlay) |
| M | Toggle mission control |
| T | Toggle activity timeline |
| Ctrl+F | Toggle cross-agent search |
| V | Toggle fog of war |
| H | Toggle territory heatmap (no hero selected) |
| F9 | Toggle quest log |
| F12 | Toggle message log |

## Alliance Hall

| Key | Action |
| --- | --- |
| B | Toggle Notice Board |

## Hero Coordination

| Key | Action |
| --- | --- |
| H | Handoff work to a new hero (hero selected) |
| Shift+H | Fork hero with full context (hero selected) |

Both support cross-client provider selection — you can fork a Claude Code hero into a Cursor hero or hand off from OpenCode to Claude Code.

## Town Hall Commands

| Key | Action |
| --- | --- |
| Q | Spawn a Claude Code agent |
| W | Spawn an OpenCode agent (requires OpenCode installed) |
| E | Spawn a Cursor agent (requires Cursor CLI installed) |
| R | Open worktree picker |
| A | View active sessions |
| F | Toggle integrated terminal |

## Terminal

| Key | Action |
| --- | --- |
| F | Create first terminal (if none); otherwise toggle panel |
| Ctrl+T | Create first terminal (if none); otherwise toggle panel |

## Permission Approval

| Key | Action |
| --- | --- |
| Y | Approve pending permission request |
| N | Deny pending permission request |

## Help

| Key | Action |
| --- | --- |
| ? | Show/hide keyboard shortcuts reference |
| F1 | Open the Field Manual (help guide) |
